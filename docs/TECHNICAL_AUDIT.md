## 6. Bundled Next.js 16.4 docs — relevant findings
Read from `node_modules/next/dist/docs/` (these supersede general knowledge):
- **`proxy.ts`** replaces `middleware.ts`; runs on Node.js runtime; use `matcher` to skip `_next` and static files. Server Functions are POSTs to the page route — **authorization must be checked inside each action**, not only in proxy.
- **Internationalization guide**: `app/[lang]/` root layout, JSON dictionaries loaded server-side, `generateStaticParams` for locales (required with Cache Components).
- **`next/root-params`**: `lang()` getter usable in any Server Component/server utility; **not** in Client Components, Server Actions or Route Handlers.
- **Cache Components**: `'use cache'` + `cacheLife` + `cacheTag`; `updateTag`/`revalidateTag` for invalidation; `cookies()`/`headers()` cannot be read in `'use cache'` and must be behind `<Suspense>`; `'use cache: private'` for per-user caching.
- **`catchError`** (`next/error`): component-level error boundaries with `retry()`.
- **Instant navigation / partial prefetching** guides apply because `partialPrefetching` is enabled.
